# Site pessoal 

Esse repósitório contém o meu site pessoal me chamo Carlos Eduardo Pereira dos Santos, estudante de Ciência da Computação na Universidade Federal de Alfenas (UNIFAL-MG).

A página apresenta um pouco sobre mim, meus passatempos, família e amigos, trajetória acadêmica, formação e formas de contato.

## Tecnologias

- HTML: estrutura e conteúdo da página.
- CSS: estilos e adaptação para diferentes tamanhos de tela.

## Como visualizar

O site está publicado no GitHub Pages: [acesse o site pessoal](https://pereira-devcarlos.github.io/site-pessoal/).

Baixe ou clone o projeto e abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Estrutura

- `imgs/`: fotos utilizadas nas galerias.
- `style.css`: estilos do site.
- `index.html`: página principal.
